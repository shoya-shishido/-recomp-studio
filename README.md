# RECOMP STUDIO v3.2 — GYM FLOW

## ジムでの使用フロー

1. 👨 男性（中級者）/ 👩 女性（初級者）のアイコンを選択します。
2. メニューまたはホームから「開始」を押します。進行中の記録は「再開」から復帰できます。
3. 各種目に**前回の日付、セットごとの重量×回数、RIR**を表示します。「詳細を見る」から前回の全記録に移動できます。
4. 前回の重量が自動入力されます。回数は未入力のままで、今日実施した回数を入力して完了にします。初回でまだ重量が入っていない場合、最初のセットを確定すると次の空欄へ重量を引き継ぎます。
5. 休憩タイマーは中断・終了・30秒延長できます。「次のセットへ」で次の未完了セットに移動します。マシンが空いていないときは画面上部の**種目クイック移動**で、別の種目へ先に進めます。
6. 終了時には完了セットだけを保存し、再度同じ種目を始めると前回として表示します。

## 利用可能なマシン

- スミスマシン・スクワット、スミスマシン・ブルガリアンスクワットを曜日別メニューへ採用。
- 男性：木曜日のスミススクワット、日曜日のスミス・ブルガリアン。バーベルスクワットなどのBIG3も維持。
- 女性：火曜日のスミススクワット、土曜日のスミス・ブルガリアン。**初心者は自重で動作練習をしてからマシンへ移行**し、セーフティとフォームを確認します。
- スミスマシンの重量は機種により異なるため、プレート重量か総重量のいずれかで**記録基準を統一**してください。

## 保存とホーム画面追加

- 記録は端末・ブラウザ内の `localStorage` に保存されます。プロフィール間では別の保存領域（旧版の `me` / `wife`）を使用します。
- 旧版のJSONバックアップに対応。切り替え前は必ずJSONのバックアップを作成してください。
- HTML単体でも動きますが、PWAとして使うにはフォルダ一式をGitHub PagesなどのHTTPSに配置してください。
- GitHub Pages（新しい空のリポジトリ）では、`index.html` とその他の同梱ファイルをリポジトリ直下にアップロードし、Settings → Pages → Deploy from a branch → main / (root) で公開できます。サイトは公開設定により第三者から見えるため、**記録をアップロードしない**でください。
- Android Chromeで公開URLを開き、︙ →「アプリをインストール」または「ホーム画面に追加」。iPhoneならSafariの共有 →「ホーム画面に追加」。
- GitHub Pagesで公開しても記録はGitHubに同期されません。夫婦それぞれが別端末で使う場合はJSONによる手動移行が必要です。
- オフラインで開けるのは一度HTTPSでアプリを取得・インストールした場合のアプリ本体のみ。**動画の外部配信はオンライン必須**です。
